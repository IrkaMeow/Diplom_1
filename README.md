# Юнит-тестирование класса Burger

Этот проект представляет собой пакет автоматизированных юнит-тестов для модуля `Burger`.

## Описание проекта

Тесты написаны на Python с использованием фреймворка **Pytest** и встроенного модуля **unittest.mock** для изолированного тестирования компонентов.

**Особенности архитектуры реализации:**
* **Изоляция конфигурации и данных (Фикстуры):** Конфигурация тестовой среды, создание чистого объекта бургера (`new_burger`), а также базовые изолированные моки булочек (`mock_bun`), соусов (`mock_sauce`) и начинок (`mock_filling`) вынесены в файл `conftest.py`.
* **Автоматическое управление данными:** Динамическая сборка и передача списков моков в тесты реализована через кастомную фикстуру-фабрику `ingredients` с использованием встроенного механизма `request.getfixturevalue`.
* **Расширенная параметризация:** Комбинации ингредиентов для расчета стоимости и различные варианты наполнения чека покрыты линейными тестами с помощью декоратора `@pytest.mark.parametrize` с флагом `indirect`.

**Проект покрывает следующие функциональные блоки (методы):**
* **Инициализация объекта (`__init__`):** Проверка корректного стартового состояния объекта — отсутствие булочки и пустой список ингредиентов.
* **Установка булочек (`set_buns`):** Валидация успешного сохранения переданного объекта булочки в свойствах бургера.
* **Добавление ингредиентов (`add_ingredient`):** Проверка последовательного добавления нескольких компонентов (начинки и соуса) и сохранения их точного порядка в списке.
* **Удаление ингредиента (`remove_ingredient`):** Проверка корректного удаления элемента из списка по его индексу с сохранением остальных позиций.
* **Перемещение ингредиента (`move_ingredient`):** Тестирование точного изменения позиции элемента в списке (сдвиг соуса на место начинки) с контролем индексов.
* **Расчет стоимости (`get_price`):** Параметризованная проверка формулы расчета цены для 4 сценариев: пустой бургер, только с соусом, только с начинкой, а также полный бургер.
* **Печать чека (`get_receipt`):** Параметризованная валидация строкового вывода чека по шаблону, проверка регистра типов ингредиентов, пустых строк и корректности отображения итоговой стоимости.

## Как установить проект

1. Клонируйте репозиторий с проектом или распакуйте архив в рабочую папку.
2. Откройте терминал в корневой папке проекта (`W:\Diplom_1\`) и установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Как запустить автотесты

Вы можете запустить пакет тестов с выводом подробной информации о каждом тест-кейсе в консоль.

* **Запуск тестов :**
  ```bash
  python -m pytest -v
  ```


## Проверка покрытия кода (Coverage)

Инструмент **pytest-cov** позволяет измерить точность покрытия исполняемого кода тестами. Данные автотесты обеспечивают **100% покрытие** класса `Burger`.

Чтобы запустить тесты и открыть отчёт о покрытии, выполните команду:
* **Windows (PowerShell):**
  ```bash
  python -m pytest --cov=praktikum.burger --cov-report=html; Start-Process htmlcov/index.html
  ```

* **macOS:**
  ```bash
  python -m pytest --cov=praktikum.burger --cov-report=html && open htmlcov/index.html
  ```

* **Linux:**
  ```bash
  python -m pytest --cov=praktikum.burger --cov-report=html && xdg-open htmlcov/index.html
  ```
